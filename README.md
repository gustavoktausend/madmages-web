# MadMages

Versão web do MadMages, um jogo de cartas de magos (Godot 4.7).

**Jogar:** https://gustavoktausend.github.io/madmages-web/

Funciona no navegador do computador e do celular deitado. No celular, dá para instalar como app: no iPhone e no iPad, Compartilhar → Adicionar à Tela de Início; no Android, Instalar app no menu do navegador. O progresso fica salvo no navegador do aparelho.

Este repositório guarda só a exportação web do jogo.
